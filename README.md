# 霓虹弹珠厅

## 安装

```bash
npm install
```

## 本地启动

```bash
npm run dev
```

## 存档槽

侧栏“存档槽”提供三个互相独立的快照槽：

- “存入”把当前这一局的完整快照写入对应槽（球的位置与速度、机关开合、连锁/奖励剩余时间、剩余球数、轻推次数、挡板姿态等），不经过操作重放；
- “读回”只替换正在打的这一局，生涯徽章、历史对局与最佳分原样保留，三个槽互不影响；
- 槽内快照损坏或格式版本对不上时，当前局一字段不动，并在界面上把该槽标记为损坏，且不会覆写磁盘上读不懂的旧数据；
- 旧快照缺少后续版本新增的机关时，缺失机关按默认关闭态补齐，整份存档仍然可以接着玩。

生涯记录与三个槽位共同存放在 `localStorage` 的 `jdk023.neon-bumper.v1` 键下（blob 版本为 2，兼容读取旧的 v1 记录）。

## 测试

```bash
npm run test:slots
```

该命令通过 Vite SSR 在内存版 `localStorage` 上跑存档槽的集成断言，覆盖快照往返、损坏隔离、旧机关补齐、槽间独立与生涯数据不被覆盖等场景。
